# PlanDocente | Generador Inteligente de Planificaciones Semanales EEB

Aplicación Web Progresiva (PWA) de generación automática de planificaciones semanales didácticas para docentes de **Educación Escolar Básica (EEB) de Paraguay**.

## 🌟 Características
- **100% Client-Side:** No requiere servidor backend, funciona directamente en GitHub Pages.
- **IA Gemini Multimodal:** Analiza fotos de páginas de libros de texto para redactar Unidades, Temas, Capacidades, Indicadores y Momentos Didácticos.
- **Compilación de Word (`.docx`) en el Navegador:** Genera y descarga el archivo `.docx` respetando el formato oficial en tiempo real.
- **Optimizado para Celulares y Tablets:** Barra de días pegajosa, carga múltiple de imágenes y diseño fluido.

## 🚀 Despliegue en GitHub Pages
Para habilitar la aplicación en tu enlace público `https://intileandro.github.io/PlanDocente/`:
1. Sube los archivos `index.html`, `style.css`, `script.js`, `manifest.json`, `sw.js` a la rama `main` de tu repositorio `IntiLeandro/PlanDocente`.
2. Ve a **Settings -> Pages** en GitHub y selecciona la fuente `Deploy from a branch: main / (root)`.
3. ¡Listo! Abre el enlace desde cualquier celular o computadora.
